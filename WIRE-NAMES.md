# NFCom documented-context JSON names

The SDK preserves the existing stable atom/struct identifiers and all three dotted/literal-star NFCom wire keys in NfcomDocumentedGroup2114. The exact native audit covers all 7,631 public Rust fields; serializers, parsers and extension collision checks use actual JSON names, even when a field is absent. Distinct underscore extensions remain separate.

Correctly serializing this documented contextual component does not establish its placement in an actual fiscal operation or authorize sending that context. Exact metadata/audit pins are in native/PROVENANCE.json.
